# Privacy Policy for Vivid Dark

**Last Updated: 2026-04-30**

## No Data Collection

Vivid Dark does not collect, store, transmit, or share any user data whatsoever.

## What Vivid Dark Does:

- Applies dark mode CSS to web pages locally on your device
- Saves your theme preferences (ON/OFF state and selected color) using Chrome's local storage API
- All settings remain on your device and are never sent to any server

## Permissions Explained:

- **storage**: Used only to remember your theme preferences locally
- **activeTab**: Allows temporary access to the current tab to apply dark mode
- **scripting**: Injects CSS themes into web pages at the optimal time
- **host permissions** (<all_urls>): Required to apply dark mode on all websites you visit

## Third-Party Access

Vivid Dark does not use any third-party analytics, tracking, or advertising services.

## Your Rights

Since no data is collected, there is no data to access, delete, or export.
